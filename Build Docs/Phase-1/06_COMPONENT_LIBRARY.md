# Phase 1 Component Library Prompt

Create a reusable component library suitable for the entire Royal Packaging CRM.

## Primitive components

Implement or establish:

- Button
- Input
- Textarea
- Select
- Checkbox
- RadioGroup
- Switch
- Slider
- Badge
- Card
- Dialog
- Sheet
- Tabs
- DropdownMenu
- Tooltip
- Popover
- Separator
- Progress
- Spinner
- Skeleton

## Application components

Also establish:

- AppShell
- Sidebar
- TopBar
- PageHeader
- SectionHeader
- MetricCard
- DataTable
- StatusBadge
- EmptyState
- ErrorState
- LoadingState
- SearchField
- FilterBar
- ConfirmDialog
- FormField

## Accessibility

Components must have:

- visible focus states
- semantic labels
- keyboard support
- appropriate ARIA attributes where necessary
- adequate touch targets

## Data surfaces

The product is operational software, so tables and dense information surfaces are important.

Create a table foundation that can later support:

- inventory
- tasks
- payroll
- employees
- orders
- clients
- audit logs

## Status system

Create a consistent status-badge approach capable of representing:

- success
- warning
- error
- info
- neutral

Do not hardcode business-specific colors throughout individual pages.
