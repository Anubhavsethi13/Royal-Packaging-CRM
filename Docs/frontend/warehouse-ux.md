# Warehouse UX

Loading and unloading remains a local scanner simulation. The queue prioritizes task code, material, source, destination, status, SLA, and timer visibility. Coarse-pointer styles increase action targets and task-row height; narrow layouts stack the queue and scanner panel while keeping the table and dialog content scrollable.

Actual scanners, RFID, printers, scales, device connectivity, offline queues, and server-side task transitions remain deferred until hardware and operating-policy questions are answered.
